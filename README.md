Setup:
 
    1. Download the entire "WINDOWS" or "LINUX" folder.
            The game relies on a folder for its fonts and save data.
    2. Extract the folder by right clicking, then pressing extract all. You can safely move the "WINDOWS" or "LINUX" folder out.
	    You can also rename that folder to ARTIFICE if you wanted.
    3. Running the EXE or BIN file will run the game itself. All save data is under "artifice/artifice.sav".
            If you want to transfer your save, just copy the save AND your save keys into a new artifice folder directory.


FAQs:

    Q: Can I move the game?
    A: Yes, make sure to move everything in the ARTIFICE folder. crt.py, saveEncryption.py, ARTIFICE.exe, etc

    Q: Do I need to have the images and stuff in the artifice folder?
    A: YES. ARTIFICE is built around these assets. Use them, they don't take up much space.

    Q: Will you update this?
    A: Artifice will continue receiving updates, and have periodic release to play testing.

    Q: Why are the playtest files being modified without a full playtest update?
    A: Hotfixes, performance updates, and adding support are just a few of the main reasons.
